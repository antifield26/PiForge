# ROADMAP — 里程碑规划

## P0 — 地基（出口：可登录、可下发编码任务、可观测、白名单生效、备份可恢复）

**目标**：打通安全入口、OpenCode 适配器、控制台只读监控、白名单 systemd、备份与恢复演练。

**依赖顺序**：
```
P0.1 项目骨架与文档固化
  → P0.2 SQLite wb.db + 认证
  → P0.3 部署 OpenCode serve（localhost）+ 适配器契约测试
  → P0.4 Agent 会话下发 + SSE 流式进度
  → P0.5 控制台只读监控（温度/负载/内存/SD 写入）
  → P0.6 systemd 白名单 + 审计
  → P0.7 备份脚本 + NAS/本地 + 校验 + 恢复演练
  → P0.8 Cloudflare 入口接线 + 密码登录联调
  → P0.9 写入减负核验（WAL/批量/重启 journald）
```

| ID | 标题 | 出口标准（含实机） | 预估 | 风险 |
|---|---|---|---|---|
| P0.1 | 骨架与配置 | monorepo 可 `npm run build`；systemd unit 草稿；文档链齐全 | 0.5d | 低 |
| P0.2 | 认证与 wb.db | 登录/登出/会话 TTL；WAL 生效；密码哈希正确 | 1d | 中（哈希/会话） |
| P0.3 | OpenCode 部署+适配器 | `opencode serve` 绑 127.0.0.1；`/api/info` 通；契约测试通过；RSS 记入 RESEARCH | 1d | 中（二进制/SSE） |
| P0.4 | Agent 任务流式 | 外网登录后下发真实编码任务，时间线见流式输出；权限 ask 可回复 | 1.5d | 高（事件映射） |
| P0.5 | 控制台只读 | 实时温度/负载/内存/SD 写入；图表 5min 聚合落盘 | 1d | 低 |
| P0.6 | 白名单+审计 | 白名单外启停返回 403 并审计；白名单内可控 | 1d | 中（权限） |
| P0.7 | 备份+恢复演练 | 备份成功+校验；从备份恢复 wb.db 一次成功 | 1d | 高（NAS） |
| P0.8 | 公网入口 | 外网经 CF + 密码进入工作台；OpenCode 不直接暴露 | 0.5d | 低 |
| P0.9 | 写入减负核验 | WAL+NORMAL；监控批量；重启后 journald 不落盘；写入日增量报告 | 0.5d | 中 |

**P0 综合出口（最终验收基线）**：
1. 外网设备经密码登录工作台；
2. 向 OpenCode Agent 下发真实编码任务并看到流式进度；
3. 控制台实时显示温度/负载/SD 写入统计；
4. 白名单外服务启停被拒；
5. NAS（或本地）备份成功且完成一次恢复演练。

**P0 合计预估**：约 8 人日。

## P1 — 核心模块（个人工作台 + 控制台深化 + Agent 浏览）

**目标**：待办/笔记/书签/云盘可用；控制台完整运维；Agent 项目/会话浏览与任务管理。

**依赖顺序**：
```
P0 出口
  → P1.1 todos/notes CRUD + UI
  → P1.2 bookmarks + 云盘文件
  → P1.3 journald 日志查询 UI + apt 更新提醒
  → P1.4 SD 寿命估算与告警
  → P1.5 Agent 项目/会话列表、任务状态
  → P1.6 备份策略配置与失败告警 UI
```

| ID | 标题 | 出口标准 | 预估 | 风险 |
|---|---|---|---|---|
| P1.1 | 待办+笔记 | 增删改查、标签、搜索；实机浏览器可用 | 1d | 低 |
| P1.2 | 书签+云盘 | 书签夹；文件上传/下载/列表（本地存储先） | 1.5d | 中（存储） |
| P1.3 | 日志+apt | 按服务查 journald（volatile 窗口）；apt 列表提醒 | 1d | 低 |
| P1.4 | SD 寿命 | 累计写入、日写入、估算寿命天数；阈值告警 | 0.5d | 低 |
| P1.5 | Agent 浏览 | 会话/消息/项目列表；任务状态徽章 | 1d | 中（API 变动） |
| P1.6 | 备份告警 | 失败通知、运行历史、手动触发 | 0.5d | 低 |

**P1 合计预估**：约 5.5 人日。
